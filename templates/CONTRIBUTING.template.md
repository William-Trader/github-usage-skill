# 贡献指南

## 提 Issue

- 先搜索是否已有相同问题
- 写清：现象、复现步骤、期望结果、实际结果、环境版本

## 提 PR

1. Fork 并 clone
2. 新建分支：`fix/具体问题` 或 `feat/功能名`
3. 只改必要文件，一次只解决一个问题
4. 提交信息用 `fix: / feat: / docs:`
5. 本地跑测试
6. 开 PR，说明动机与验证方式

## 提交信息

```
<type>: <简短说明>

<可选正文>
```

type：feat / fix / docs / chore / refactor / test

## 行为准则

尊重、具体、对事不对人。
